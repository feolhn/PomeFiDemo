# Skill Lab Widget UI 设计指南

> 基于 `ui_skill_lab_widget.jpg` 灰度稿的设计原则总结  
> **落地风格**: shadcn/UI  
> **注意**: 本稿仅示意组件结构、层级关系，颜色/位置非最终标准

---

## 1. 设计原则

### 整体风格
- **极简理性** - 金融分析产品的专业感
- **信息层级清晰** - 通过字号、字重、间距区分重要性
- **模块化组件** - 可复用的 Section 卡片结构
- **shadcn/UI 风格** - 最终落地基于此设计系统

---

## 2. 字体规范

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| 一级标题 | 20px | Bold (600) | Skill 名称、页面大标题 |
| 二级标题 | 16px | Medium (500) | Section 标题、关键指标 |
| 三级内容 | 14px | Regular (400) | 正文、描述文字 |
| 辅助信息 | 12px | Regular (400) | 时间戳、元数据、标签 |

### 特殊文字
- **数据指标**: 32px-40px Bold（大数字强调）
- **评分数字**: 与标题同行，中等字重
- **标签文字**: 12px，Capsule 标签内

---

## 3. 间距规范

所有间距均为 **4 的倍数**，保持视觉节奏：

| 场景 | 间距 |
|------|------|
| 页面边距 | 16px / 20px |
| 卡片内边距 | 16px |
| Section 之间 | 12px - 16px |
| 元素之间 | 8px - 12px |
| 行间距 | 4px / 8px |
| 图标与文字 | 4px - 8px |

---

## 4. 组件结构

### 4.1 Skill Header（头部信息区）

```
┌─────────────────────────────────────────────┐
│  [标题]                [收藏] [分享] [关闭]  │  ← 顶部操作栏
│  [类型] [创建者信息]                         │
│                              [数据] [数据]   │  ← 互动统计
└─────────────────────────────────────────────┘
```

**结构要点：**
- 标题与操作按钮左右分布
- 类型标签与创建者信息次级展示
- 收藏数、再创作数右对齐
- 支持关闭/返回操作

### 4.2 Collapsible Section（可折叠区块）

```
┌─────────────────────────────────────────────┐
│  [Section 标题]                    [展开▼]   │  ← 标题栏可点击
├─────────────────────────────────────────────┤
│  [内容区域]                                  │  ← 展开后显示
└─────────────────────────────────────────────┘
```

**结构要点：**
- 标题栏整行可点击展开/折叠
- 右侧展开指示图标（▼/▶）
- 内容区域独立内边距
- 默认折叠状态（除关键 Section 外）

### 4.3 Tag Chips（标签组）

```
┌─────────────────────────────────────────────┐
│  [标签1]  [标签2]  [标签3]                   │
└─────────────────────────────────────────────┘
```

**结构要点：**
- 横向排列，间距 8px
- 圆角胶囊样式
- 标签文字简短（2-6 字）
- 支持组合标签（如：类型 + 值）

### 4.4 Chart Card（图表区块）

```
┌─────────────────────────────────────────────┐
│  [Section 标题]                     [展开▼]  │
├─────────────────────────────────────────────┤
│  [关键指标提示]              [趋势图标]      │
│                                             │
│           [图表区域]                         │  ← 居中，占主要空间
│                                             │
│  [数据来源说明]                              │
│  [AI 洞察文字]                               │
└─────────────────────────────────────────────┘
```

**结构要点：**
- 有图表的内容均参考此格式
- 图表上方：关键数据摘要 + 趋势指示
- 图表居中，视觉占比大
- 图表下方：数据来源时间戳
- AI 洞察：自然语言总结（1-2 行）

### 4.5 Metric Card（指标卡片）

```
┌─────────────────────────────────────────────┐
│  [Section 标题]                     [展开▼]  │
├─────────────────────────────────────────────┤
│                                             │
│              [计算数字%]                     │  ← 超大数字居中
│        [计算参数说明]                         │
│                                             │
│     [AI 洞察文字]                            │
│                                             │
└─────────────────────────────────────────────┘
```

**结构要点：**
- 不涉及图表的内容均参考此格式
- 大数字垂直居中突出
- 计算参数小号字说明
- 洞察文字在指标下方
- 整体居中对齐或左对齐


### 4.7 Comments Section（评论区）

```
┌─────────────────────────────────────────────┐
│  共 [999+] 评论                              │
├─────────────────────────────────────────────┤
│  [头像] [输入框占位符]                       │
├─────────────────────────────────────────────┤
│  [头像] [用户名]              [行为标签]     │
│       [评论内容]                             │
│       [图片/媒体]                            │
│       [时间] [地点] [回复]      [♡ 点赞数]   │
├─────────────────────────────────────────────┤
│  [头像] [用户名]              [行为标签]     │
│       [评论内容]                             │
│       [展开XX条回复]                         │
└─────────────────────────────────────────────┘
```

**结构要点：**
- 评论总数作为标题
- 输入框简化展示（可点击展开）
- 评论条目：头像 + 内容结构
- 行为标签右对齐（#收藏了该Skill）
- 互动数据底部排列
- 支持嵌套回复展开

### 4.8 Bottom Navigation（底部导航）

```
┌─────────────────────────────────────────────┐
│      [图标]            [图标]                │
│      Skill Lab        详情页                 │
└─────────────────────────────────────────────┘
```

**结构要点：**
- 两等分布局
- 当前页高亮指示
- 固定在视口底部

## 5. 内容层级

### 信息优先级
1. **P0 - 核心信息**: Skill 名称、关键数据、图表
2. **P1 - 重要信息**: Section 标题、AI 洞察、匹配度
3. **P2 - 辅助信息**: 类型标签、创建者、数据来源
4. **P3 - 元信息**: 时间戳、互动数、评论

### 展开策略
- **默认展开**: 图表 Section、关键指标 Section
- **默认折叠**: 属性 Section、匹配度 Section、评论区
- **折叠逻辑**: 非核心信息默认收起，减少首屏负载

---

## 6. 文案规范

### 语气风格
- **冷静理性** - 华尔街分析师口吻
- **结构化** - 先事实后判断
- **轻微犀利** - 可带毒舌，不失专业
- **克制表达** - 避免情绪化词汇

### 典型句式
| 场景 | 示例 |
|------|------|
| 集中度警示 | "看似买了一堆，其实都一样" |
| 风格不匹配 | "知行不一警告" |
| 数据洞察 | "你看上去买了一箩筐基金，其实都一样" |
| 风险提示 | "估值处于历史中偏高区间" |

---

## 7. shadcn/UI 落地建议

### 推荐组件
| 组件 | shadcn 组件 | 用途 |
|------|-------------|------|
| 卡片容器 | `Card` | Section 外层 |
| 可折叠区块 | `Collapsible` | Section 展开/折叠 |
| 标签 | `Badge` | 属性标签、行为标签 |
| 按钮 | `Button` | 操作按钮、关闭 |
| 头像 | `Avatar` | 评论用户头像 |
| 输入框 | `Input` | 评论输入 |
| 分隔线 | `Separator` | Section 分隔 |

### 自定义需求
- 图表组件：使用 `recharts` 或自定义 SVG
- 底部导航：自定义固定布局
- 大数字指标：自定义样式

---

## 8. 响应式策略

### 移动端（优先）
- 单列布局，全宽卡片
- 底部固定导航
- 触摸友好（最小 44px 点击区域）

### 桌面端（扩展）
- 最大宽度限制（如 480px 或 720px 居中）
- 侧边留白
- 悬停交互补充
